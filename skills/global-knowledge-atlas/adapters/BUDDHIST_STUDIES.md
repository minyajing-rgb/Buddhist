# Buddhism Adapter Example

This adapter applies Global Knowledge Atlas to Buddhist Studies.

## Entities
- Work: abstract Buddhist text/work
- Version: language/recension/translation
- Witness: manuscript, print, woodblock, inscription
- Canon: Pāli / Chinese / Tibetan / historical canon
- Person: Buddha, disciples, translators, authors, scholars
- Place: origin, translation center, findspot, holding
- Concept: dukkha, anātman, śūnyatā, tathāgatagarbha, etc.

## Core crosswalk IDs
- SuttaCentral IDs
- Taishō / CBETA IDs
- Tohoku (Toh) IDs
- BDRC Work/Instance IDs
- manuscript shelfmarks / catalog IDs

## Required distinction
Work ≠ Version ≠ Witness.
Parallel ≠ identical.
Traditional attribution ≠ historical conclusion.

## Research lanes
- Early Buddhist parallels
- Pāli canon
- Chinese Āgamas / canons
- Sanskrit & Gāndhārī witnesses
- Tibetan Kangyur/Tengyur
- East Asian compositions/commentaries
- living Buddhist traditions
- modern scholarship/public reception

## Public path
Story → Timeline → Map → Text → Compare → Witness → Debate.
