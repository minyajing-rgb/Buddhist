# Global Knowledge Atlas Skill

Reusable research-production workflow extracted from the Dharma Atlas / Buddhist project.

## Use it for

- Bible / Christianity
- Islam / Qur'an / Hadith
- Hindu / Vedic / Sanskrit traditions
- Chinese classics
- mythology / folklore
- history of science
- game history / genre taxonomy
- art history
- medicine/history of medicine
- any field where sources are fragmented across texts, people, places, versions, archives and public interpretation

## Start

Read:
1. `SKILL.md`
2. `references/RESEARCH_METHODS_MATRIX.md`
3. `references/HARVARD_HDS_METHODS.md`
4. `references/PUBLIC_COMMUNITY_KOL_METHODS.md`
5. `templates/DOMAIN_ADAPTER.md`

Then create a domain adapter and run database-first.

## Core output

```
Source universe
→ canonical entities
→ crosswalks
→ material evidence
→ people/places/timeline
→ bibliography/controversies
→ community/KOL/public reception
→ media
→ QA
→ beginner website
```
