# Global Knowledge Atlas｜执行手册 v1.1

更新：2026-09-19。适用对象：学术、历史、科学、文化、宗教、艺术、民俗与公共知识地图。

这是本项目综合设计的工作流，不是哈佛官方认证、课程复制或某一机构的统一研究方法。HDS相关原则与图书馆资源在下方逐项注明；口述史、互联网伦理、文献编码、实验复现分别使用相应领域的方法，不能统称为“哈佛研究法”。不存在能一次穷尽所有学科的固定方法列表：以下是可扩展的核心操作集。

## 0. 接手项目：先读仓库，后相信总结

1. 读取默认分支、CURRENT、状态台账、实体文件、旧版和已有发布物。记录当前commit。
2. 程序统计真实记录数、唯一ID、空值、无效引用、重复来源、占位资源。以实际内容为准，不抄README的数字。
3. 对照旧版抽样：深度是否增加，还是只有字段增加？版本号变化不是研究进展。
4. 输出四种状态：资料已归档 / 证据已核验 / 界面已实现 / 公网已部署。不得合并为“已完成”。
5. 仅修改目标仓库和明确授权路径；保存旧数据。新增批次必须可diff、可回滚、可复现。

## 1. 研究协议与覆盖边界

开工前固定：研究问题、目标读者、收录对象、排除条件、时空范围、语言、主要分支、资源预算、证据阈值、停止标准。用“区域×年代×语言×流派×来源类型”覆盖矩阵，不用一个总数冒充全量。

主记录是作品、实验还是仪式？先定义单位，避免作品与章、合集与子经、理论与应用、药材与疗法、人物与账号混计。100部代表作品不等于全部大藏经；100个网页不等于100个独立证据。

每次检索写入query、平台、语言、过滤条件、执行时间、命中量、筛入/排除理由。无结果必须区分：确实没找到、库不覆盖、权限限制、页面失效、检索词不匹配。不要把“未检得”写成“不存在”。

## 2. 方法操作卡：问题 → 输入 → 操作 → 产物 → 验收

|编号/方法|要解决什么|最小操作|必须交付|错误门禁|
|---|---|---|---|---|
|M01 领域界定|什么算本领域|列核心/相邻/争议边界；确定分析单位；与用户目标对照|scope协议、分类树、排除表|不得边搜边偷偷扩口径|
|M02 HDS语境化阅读|谁在何时何地表达什么|标群体、年代、地点、社会条件；区分内部信仰与外部分析|立场与语境卡|不得“某宗教都认为”[H1]|
|M03 信息版图|知识分散在哪里|并列论文、书、文本、数据、图像、声音、档案；标权限|来源地图、在线/线下入口|机构主页不是作品直达[H2,H3]|
|M04 多语言检索|语言偏差遗漏了什么|原文、转写、旧拼写、译名分别检索；记录零结果|别名表、检索日志|不能只搜英文/中文就称全球|
|M05 书目综述|领域有哪些关键论点|先综述和注释书目；后原著；分经典、近期、反方、非英语|paper/book级书目|引文题名必须核验，不生成假DOI[H2]|
|M06 前后向引文追踪|观点从哪来、后来怎样|逐级追参考文献；寻找后续引用、反驳、修订|citation边、观点时间线|转引不冒充读过原文|
|M07 来源批判|材料能证明哪个问题|问作者、时间、用途、受众、利益、传递链；区分原件/编辑/分析|source profile|一手性由研究问题决定，不由格式决定|
|M08 文献学|术语、句子、译名为何不同|锁定底本/版次/语种；逐段对照；保留原词与定位|版本对照、词表、注记|译文相似不能证明同一底本|
|M09 校勘学|异文与版本关系|登记见证；align到段/行；记录增删、重排与疑读；保留不能对齐|variant apparatus、关系类型|不能硬画唯一祖本树[T1]|
|M10 书籍形制研究|实物怎样制成|记录材料、尺寸、叶序、装订、缺损、修复；照片对照馆藏号|object record|扫描页数不等于原卷完整|
|M11 古文字/书体|字形可支持什么年代|与有可靠纪年的比较材料对读；注明比较范围和专家判断|有来源的年代区间|AI识字/图像相似不等于鉴定|
|M12 考古语境|物件原来在什么环境|核出土地、层位、发现报告、扰动与收藏过程|发现事件与出处边|发现地不等于成书地|
|M13 收藏溯源|原件怎么到了今天的馆|串联旧藏、购藏、转移、登记、馆藏号；保留链条断点|provenance ledger|不可把研究目标馆当作实际持有馆|
|M14 接受史|后来的人怎样理解它|取不同时代注释、艺术、讲经、教材和媒体；分别编码|接受事件与释义变化|当代用途不是古代起源证据|
|M15 概念谱系|同一词在不同时期是什么|抽原文语境、对立词、译词；画变化而非一词一义|concept-time map|同名词跨学科不得自动合并|
|M16 口述史|亲历者如何记忆|知情同意、访谈提纲、录音许可、时间标记、讲述者复核与撤回边界|转写、同意范围、分析备忘|记忆证言不自动等于事件客观记录[O1]|
|M17 实践者访谈|隐性知识怎么操作|问具体一次实例、步骤、失败、例外、学习渠道；回访核对|practice recipe、例外表|大师声望不等于疗效或历史证据|
|M18 民族志|群体在现实中如何生活|说明观察位置、参与程度、时长；分观察笔记与解释；记录反例|田野笔记、位置反思|一个村落不代表整个传统|
|M19 数字民族志|平台怎样改变实践|记录平台机制、公开程度、参与规范、取样窗口和删除变化|contextual community corpus|公开不等于可无风险再传播[A1]|
|M20 KOL论点收集|人们正在讨论什么|标视频/帖子时间、精确论点、引文、赞助；按论点而非账号计数|claim ledger、候选选题|热度不计入真实性分数|
|M21 KOL逆向溯源|一个断言能追到什么|视频→书/论文→版本/数据→原件；断链即标lead_only|来源链与断点|同一新闻稿的十次转发只算一个起源族|
|M22 公开材料验证|网上图文是否可信|核原始上传、语境、日期、地点、版本；保存合法必要证据|verification log|截图不证明发生时间或原始身份|
|M23 调查研究|某种观点有多常见|定义总体、抽样、问项、缺失与权重；报告不确定性|问卷、样本口径、汇总|评论区比例不可代表总体|
|M24 比较案例|不同地区/传统差异|预先定比较维度；列相似与相异案例；写混杂因素|comparison matrix|不能只选支持预设的案例|
|M25 GIS时空分析|什么在何时何地出现|坐标+精度+角色+日期区间+来源；明确古今地名|time-aware GeoJSON|未核年代不能偷偷赋年让地图动起来|
|M26 网络分析|人、书、地怎么相连|每条边给类型、方向、来源、日期；与缺失覆盖一起显示|typed graph|共现不是影响；连线不是因果|
|M27 语料/文本挖掘|大量文本有什么模式|固定语料版本、分词、语言、参数；人工标注样本；报告误差|可复现代码与误差样本|embedding近似不自动算平行文本|
|M28 图像/3D研究|视觉物件怎样解释|核权利与物件ID；区分实测模型、艺术复原、示意图|asset registry、说明与授权|生成图不能冒充历史现场或扫描件|
|M29 实验/复现|可检验主张是否成立|列操作定义、变量、对照、设备、数据、代码、统计与失败条件|protocol、数据与复现记录|对量子理论的隐喻不等于实验证据|
|M30 系统综述|多研究总体支持什么|预设纳排、去重、筛选、质量/偏倚评估；异质性分析|筛选流、证据表、限制|未执行完整流程不得自称系统综述|
|M31 争议综合|学者为什么不同意|署名逐项：结论、版本/数据、方法、反证、限制、后续回应|attributed position map|不能用虚构“学界共识”；争议不是强行五五开|
|M32 小白教学转译|用户如何点一下就懂|问题→故事→一张图→概念→证据→争议→继续读|可点击学习路径|不删掉影响结论的不确定性换取故事顺畅|
|M33 质量与发布|怎样判断真进展|审ID、字段内容、来源关系、权利、覆盖、链接类型；跑UI测试|机器审计+人工抽检+发布状态|schema通过不是史实通过；文件存在不是网站上线|

以上操作是本项目的执行设计；仅标注的对应原则/资源可归因于下列机构。不是宣称上述所有方法由HDS提出。

## 3. 三个常见研究者路线，不能混用证据标准

### 学术路线
问题界定 → reference/annotated bibliography → 原典/原始数据 → 多语言资料 → 关键论文和专著 → 对照异议 → 可定位论证。先知道讨论了什么，再回到具体证据。Harvard Library/HDS的入口提供书目、数据库、档案等资源；访问权限和全文可见性需逐项确认。[H2,H3]

### 民间、传承人与实践者路线
从具体地方、家庭、组织或传承出发，记录做法、词汇、师承说法、使用情境、经验和变迁。输出应写“某人于某地如此讲述/实践”，不直接升级成古代事实、医学疗效或宇宙客观机制。应有可撤回/限用条件、匿名处理与必要的社区回馈。[O1,A1]

### 公众知识与KOL路线
以大众问题作为入口，用视频、故事、图解组织信息，再让每个重要结论能回查资料。BU对Religion for Breakfast的2018年报道记录了“学术但易理解”的宗教知识视频路线；这是有日期的案例，不使用当年的粉丝数字代表今天。[K1] Let's Talk Religion的创作者页是其自身对研究取向的说明，不能当作第三方鉴定。[K2]

可借鉴表达方式，不能复制别人的脚本/图片/付费研究。每集输出：hook、主要论点、来源定位、适用范围、争议点、原典入口、公众常见误读、进一步阅读。商业合作信息单独记录，不因有赞助自动否定内容，也不忽略潜在利益冲突。

## 4. 100部Crosswalk的最低诚实结构

每部都要有：稳定Work ID；名称/语言/别名；实体类型；版本或合集范围；canonical ID；typed relation；source locator；年代类型与状态；写本与馆藏证据类型；书目；公众解释；问题与下一步。

其中“馆藏待查”“全文未翻译”“年代有争议”“尚未发现更早见证”是四种不同状态。URL分为：实体/版本页、目录记录、合集页、查询页、机构主页。只有前两种可能是作品级入口，且目录存在不代表可以阅读全文。

L3不得通过把年代移出定义、把写本换成收藏背景来人为完成。保留旧版本的reported_level，但另增assessed_level和维度级状态。没有第二系统映射的记录不能一律称L2；同样不能强行给每部找一件并不存在的实体写本。

### 深度判定

- L0：发现线索。
- L1：至少一个作品级权威记录；身份可回查。
- L2：两个以上标识系统/明确的跨版本对应，关系有证据。
- L3：L2 + 逐部年代论证 + 确切见证/实物证据；没有存世见证时，以署名的负面研究结果替代，而不是空字段。
- L4：L3 + 已定位的专著/论文、署名争议、反证和限制。

自动导入的bibliography不等于已经读过这些论文。版本页有出版年份不等于古代作品的创作年份。检查链接可以证明访问结果，不能证明历史结论正确。

## 5. 学科迁移

|领域|主实体|关键关系|额外门禁|
|---|---|---|---|
|宗教/思想史|文本、版本、人物、传统、实践|译自/平行/注释/传统归属|信仰表达与历史分析分层|
|文学/艺术|作品、版本、表演、物件、作者|改编/借用/接受/收藏|著作权、归属和图像权利|
|地方史/民俗|事件、地点、社区、档案、口述|发生于/记忆/传承/迁移|在地语境、同意、不可泛化|
|自然科学|概念、模型、定理、实验、数据|推出/检验/近似/反例/复现|数学推导、实验事实和哲学解释分别标注|
|医疗/疗愈研究|干预、对象、结局、研究、风险|研究评估/相关/因果/不良反应|传统用途不等于有效性；不能从个案给诊疗建议|
|商业/游戏研究|产品、市场、公司、指标、实验|竞争/发行/投资/增长归因|时间戳、地区、口径；收入不等于利润，相关不等于增量|

换领域时复制skill，不复制佛教结论；替换adapter中的对象、核心库、语言、证据标准和示例。科学研究不能沿用神学断言标准，民俗记录也不能被实验室标准抹去其文化价值。

## 6. 文件合同与验收

输入：`domain brief + canonical manifest + existing data + source registry`。

每批输出：
- `search-log`：查询、时间、筛选和负面结果。
- `claim-ledger`：论点、说话人、来源定位、证据类型、反证、审核者。
- `crosswalk`：Work/Version/Witness/Parallel分离；唯一ID与引用完整。
- `bibliography`：题名、作者、年份、版次、稳定URL/DOI、是否读到全文。
- `media-registry`：所有者、授权、使用方式、alt、关联实体。
- `qa-report`：字段内容而非字段存在、原始/派生分离、覆盖缺口。
- `release-manifest`：提交号、数据文件哈希、测试结果、部署状态。

网站生成顺序：审计数据 → 生成含全部记录的审阅版 → 搜索/筛选/对比/证据链测试 → 修复 → 人工内容与权利验收 → 公网发布。审阅版可以验证内容与交互，但必须标明数据缺口，不得以“完整官网”代替尚未达标的学术数据库。

UI标准：默认从问题和故事开始；逐层展示专业字段；手机可用；正文可放大；键盘可达；搜索有空态；未知年代不进历史年筛选；现代馆藏与古代传播图层分离；视频与3D无资产时不出现假播放按钮。

## 7. 可复制启动指令

> 使用 Global Knowledge Atlas skill 为【学科】建立面向小白、可逐层深入的知识地图。先读取现有仓库与CURRENT；以【对象范围】为单位，覆盖【地区/语言/年代】。先审计、补数据和证据，再生成网站。使用EXECUTION_PLAYBOOK_v1.1；区分学术、实践、KOL和机器导入层；输出逐条来源、未知/争议与缺口。保留原文件，不以schema或记录数量冒充研究完成。
