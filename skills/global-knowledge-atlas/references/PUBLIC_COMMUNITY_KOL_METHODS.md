# Public / Community / KOL Research Methods

## Purpose

Public sources are a **discovery, reception, testimony, and dissemination layer**. They can also be primary sources when the research question is about what the creator/community said or did.

## KOL Card

For every creator/expert/public researcher:

```yaml
person_id:
platform:
handle:
bio_claims:
expertise_claimed:
institutional_affiliations:
firsthand_access:
source_practice:
citation_density:
sponsorships:
conflicts:
known_corrections:
archive_urls:
topics:
reliability_by_topic:
notes:
```

Do not assign one global “reliability score” to a human. Reliability is claim- and domain-specific.

## Verification

1. Extract the claim exactly.
2. Find the earliest available version.
3. Identify the claimant's cited source.
4. Reverse-trace to primary/authority material.
5. Archive the public page if appropriate.
6. Search independent corroboration.
7. Look for corrections/deletions.
8. Check sponsorship/conflicts.
9. Separate factual core from interpretation.
10. Write a confidence statement.

## Forums / community research

Use forums/comments to:
- discover terminology;
- find edge cases;
- find local experts;
- identify competing interpretations;
- see what beginners misunderstand;
- observe reception.

Do not:
- expose vulnerable identities unnecessarily;
- quote searchable sensitive text without considering harm;
- turn anecdotal frequency into prevalence.

## OSINT pattern

Following open-source investigation best practice:
- identify;
- collect;
- preserve;
- verify;
- analyze;
- corroborate;
- review;
- publish.

Record tool limitations. A tool result is not automatically a verified fact.

## Ethics

Use context-sensitive Internet research ethics:
- privacy expectations;
- audience expectations;
- vulnerability;
- harm;
- consent;
- data minimization;
- quotation/searchability;
- researcher safety.
