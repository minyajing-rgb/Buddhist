# Research Methods Matrix

Use this matrix to decide **how** to investigate a question instead of relying on one default method.

| Method | Best for | Typical evidence | Main failure mode | Output |
|---|---|---|---|---|
| Philology | wording, language history | manuscripts, editions, dictionaries | treating translation as identical | variant map |
| Textual criticism | reconstructing earlier forms | multiple witnesses/recensions | forcing a single stemma | apparatus + confidence |
| Codicology | book/object construction | material, foliation, binding | ignoring later repairs | object record |
| Paleography | script/date/provenance | handwriting/script | over-precise dating | date range |
| Historical criticism | context and development | primary docs + chronology | presentism | contextual model |
| Reception history | how meanings change | commentaries, art, sermons, media | confusing reception with origin | timeline |
| Comparative studies | cross-tradition comparison | typed parallels | false equivalence | crosswalk |
| Archaeology/material culture | physical practice | objects/sites/strata | text-only bias | material map |
| Art history | visual culture | images/objects | iconography without context | visual corpus |
| Ethnography | lived practice | field observation | overgeneralizing local case | thick description |
| Oral history | memory and experience | interviews/audio | memory = event record | testimony layer |
| Sociology | groups/institutions | surveys/networks | category design bias | population model |
| Quantitative history | long-run patterns | datasets/catalogs | survivorship bias | statistical pattern |
| GIS | spatial change/transmission | coordinates/routes | false precision | map layers |
| Network analysis | relationships/influence | graph edges | edge ≠ causality | network graph |
| Bibliometrics | scholarly field structure | citations/metadata | popularity ≠ quality | research map |
| NLP/text mining | large corpus patterns | OCR/HTR/text | model/OCR error | candidate patterns |
| 3D/photogrammetry | material objects/sites | image sets/scans | surrogate ≠ original | 3D asset |
| OSINT | web-native claims | public records/media | duplicated-source illusion | verification chain |
| Content analysis | media/KOL narratives | coded samples | cherry-picking | theme/frequency table |
| Digital ethnography | online communities | posts/interactions | privacy/context collapse | community model |
| Genealogy of concepts | concept transformation | texts across time | assuming stable meaning | semantic timeline |
| Practitioner inquiry | expert practice | interviews/manuals | prestige bias | practice layer |

## Triangulation Rule

Strong conclusions normally combine at least two different method families.

Example:
- textual criticism + manuscript evidence;
- interview + archive;
- GIS + historical sources;
- KOL claim + official record + academic study.

## Negative Evidence

Record:
- searched databases;
- search terms;
- date;
- language;
- no-result outcome;
- access restrictions.

“No evidence found” is only meaningful when the search space is documented.
