Read product-definition and full approved PRD/mockups/flows/architecture. Freeze exact repo/commit/build/URL/environment/time/browser/device/locale/width. Distinguish implemented, local/preview tested, internally accepted, owner reviewed, deployed and live verified.
Use ALL concrete routes/instances, nested branches/tabs/modals/controls and required states as denominator. Diff router and visible links; add newly found pages. Create one PAGE_REVIEW_CARD per page: requirement/flow/mockup IDs, expected/actual, actual desktop/mobile image pair, content/source/locale truth, every control's destination/side effect, states, accessibility, console/network/private-access/metadata, evidence commit and defect IDs. PASS/FAIL/BLOCKED/NA_WITH_REASON; untested is BLOCKED. Report numerator/denominator, not a test-count headline.
Open actual pixels beside approved mockups. Check hierarchy/spacing/type/contrast/imagery/cropping/readability, overlap/clipping, long text, sticky bars, focus/names/touch/zoom/reduced motion. Screenshot capture, DOM tests, HTTP200 and builder self-report are not visual acceptance. Low-resolution previews are not original-image restoration; emulated viewports are not physical-device QA.
Exercise every positive/alternative/failure path: empty/invalid/long input, loading/success/no-results/error/timeout/offline/retry, denied storage/permissions, guest/auth, cancel/back/refresh/deeplink/repeat. Observe real state/network outcomes. Test applicable RLS/persistence/model/forms/payment safely; never charge, send, change private records or weaken security without authorization. Review visitor value, architecture, privacy, full locales, SEO and measured performance.
DEFECTS.json: severity, page/state/requirement, reproduction, expected/actual, evidence, owner, fixing commit, RETEST plus neighbours. P0 security/data-loss; P1 broken/missing required flow or critical visual evidence/misleading success; P2 nonblocking quality. Fix authorized issues then retest; an untested fix stays open. Gate B implemented/built; Gate C INTERNALLY_ACCEPTED requires complete coverage, actual pixels inspected, no open P0/P1 and explicitly accepted P2 exceptions. Otherwise NOT_READY; no silent scope waiver.
Gate D only after authorized deployment: inspect published/custom domains, redirect/body/title/asset hashes vs tested build; rerun every live route/locale and critical flow, console/network, SEO/canonical/lang/OG, auth and rollback. SPA200 may be wrong page. Missing candidate is NOT_DEPLOYED. Preview/rebuilt production are different targets. Never publish or repeat backups merely to pass a check.
Reuse evidence only when diff proves page AND shared data/styles/translations unchanged; unmapped changes fail closed. Record method and evidence commit. Hand over only self-checked candidate with previews, coverage, defects and exact build; do not repeatedly ask owner to request review. Templates are in canonical .agents/skills at pinned commit. COPIED, ACTIVATION_TESTED and AUTOMATION_RUNNING are separate; GitHub files alone are not global runtime activation.
