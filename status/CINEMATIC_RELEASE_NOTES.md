# Dharma Atlas cinematic website release

Source release: cinematic-4.0.

The no-text cinematic scene and six portal illustrations are permanently stored in web/garden/cinematic-assets. They are not remote hotlinks. The one-time import workflow has been removed after successful transfer. The rendered full-scene image is 1776 x 888; this is a resampled transfer of the approved artwork, not a claim of pixel-identical archival reproduction.

The visitor layer uses the approved local CSS and JavaScript, real cross-entity search, native journey and search dialogs, scene hotspots, a four-step interactive guide, local progress, daily learning cards, quiet mode and optional motion.

scripts/finish_garden.py stages these assets AFTER the legacy vector renderer so the visitor release cannot silently revert to flat SVG artwork. Missing cinematic assets fail the release. Existing research data and the quantum subsite are preserved.

Build success is not deployment success. Actual public deployment and exact image-byte verification are recorded by the release workflow in status/garden-deployment.json and status/garden-public-qa.json; screenshots are stored in its dharma-garden-website artifact.
