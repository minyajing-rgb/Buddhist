# Legacy Infographic Sources

> **STATUS: LEGACY / NOT PUBLIC-FACING**

These SVG files were the v0.1–v0.2 structural sketches used to test information architecture.

The user-facing visual standard has changed:

- final public visuals must be **PNG/JPG**;
- white, clean, modern base;
- navy typography with restrained warm-gold / lavender / teal accents;
- realistic or refined atlas-style maps where relevant;
- no heavy temple-style decoration;
- final assets will live under `docs/assets/img/`;
- the future website must not use these SVGs as its primary visuals.

The SVGs are retained only as editable historical source diagrams until the replacement PNG package is committed.
