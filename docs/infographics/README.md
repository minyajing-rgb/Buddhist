## Design rules

- 中英文并列，面向全球传播。
- SVG 为源文件：可直接在 GitHub 预览，也可嵌入网页。
- 不使用“某宗派=真、另一宗派=假”的视觉排序。
- 所有历史结论后续必须能回链到 source registry / work IDs / bibliography。
