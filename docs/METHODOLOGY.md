# Methodology｜方法论

## 1. 不使用“真/假”作为唯一二元标签

Dharma Atlas 的默认输出是：
- **Traditional attribution**：传统归属
- **Physical evidence**：物质证据
- **Cross-tradition support**：跨传统支持
- **Scholarly reconstruction**：学术重建
- **Disputed**：有争议
- **Unknown**：目前不知道

## 2. 三个实体必须分开

### Work
抽象作品。

### Version
某语言、传承、译本或 recension 的文本版本。

### Witness
具体写本、刻本、残片、碑铭或其他实体证据。

## 3. 年代至少记录两套

- **Traditional date**：传统叙述中的年代
- **Scholarly date/range**：根据文献学、写本学、历史证据提出的年代范围

不能把两者混成一个确定年份。

## 4. 地理至少分四类

- Origin / composition context
- Translation / transmission location
- Manuscript findspot
- Current holding

## 5. Parallel 关系必须分级

不要写“中文这部 = 巴利那部”。

至少标：
- close parallel
- partial parallel
- resembling parallel
- translation
- recension
- quotation
- uncertain

## 6. 大众叙事与学术证据分层

每个 Story Episode 都有两层：
1. **Story Layer**：人物、悬念、冲突、地图
2. **Evidence Drawer**：原典 ID、写本、异读、论文、争议

这样既不牺牲可读性，也不牺牲可追溯性。
