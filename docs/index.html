先理解一个规则

“最早的实体写本”不等于“佛陀本人原稿”；“不同译本”也不自动意味着“谁翻错了”。真正可靠的方法是比较多个独立传统留下的证据。

WORK

作品

抽象的文本作品，例如某一部经或某一组教说。

VERSION

版本

某语言、某传承、某一编辑或翻译形成的具体文本版本。

WITNESS

实体见证

具体写本、刻本、残片、碑铭、木板等可以直接观察的物质证据。

02｜传播不是一条线

必须区分四件事：传播地、翻译地、写本发现地、今天的收藏地。同一部作品的四个地点可能完全不同。

03｜佛典传统分支树

这不是“谁从谁进化”的宗派排行榜，而是一张文本传统关系图：早期经典、部派材料、大乘文献群、汉文与藏文大藏经、巴利传统以及大量残卷共同构成网络。

04｜怎么追“真经”？

把“真假”改写成一个可审计的问题：证据距离源头有多远？有几个独立传统支持？文本关系是什么？我们不知道什么？

05｜像连续剧一样学

先讲悬念和人物，再把证据层一层打开。普通用户停在故事层；想深挖的人继续进入写本、原文与论文。

01

佛陀为什么没有留下一本书？

从口传文化开始，而不是从“大藏经第一页”开始。

02

没有录音，几百个人怎么保存几十万字？

重复、公式化结构、共同诵读与群体校正。

03

为什么后来出现不同版本？

地区、部派、语言、底本与编辑历史开始分叉。

04

地下为什么会出现两千年前的桦树皮？

犍陀罗写本让“早期佛典”突然有了更早的物理证据。

05

丝绸之路上的“国际翻译公司”

翻译从来不是一个人的替词游戏，而可能是一套多人协作工程。

06

玄奘为什么一定要去印度？

版本差异、教学体系与源文本问题，让“亲自去找”变成知识工程。
