# Season 1｜《真经到底去哪了？》

> Story-first, evidence-backed. 每集先讲人，再讲文本；先讲悬念，再展开证据。

## EP01｜佛陀为什么没有留下一本书？
**Hook:** 如果一个改变亚洲两千多年的老师，从来没写过一本书，我们今天读到的是什么？
- 口传文化不是“没有技术”，而是一套记忆技术。
- formula / repetition / communal recitation。
- **Evidence drawer:** 早期经典共同结构；口传研究。
- **Map update:** 恒河流域。
- **Cliffhanger:** 一旦不同僧团分开生活，同一句话会不会开始变化？

## EP02｜几百个人怎么靠脑子保存经文？
- “如是我闻”不是录音标签，而是文本传统的一部分。
- 数字列表、重复句式、固定公式为什么如此多。
- **Demo:** 把现代散文与阿含/Nikāya公式结构并排。
- **Cliffhanger:** 记得住，不代表每个群体记得完全一样。

## EP03｜佛经为什么会出现不同版本？
- geographical separation
- school transmission
- oral reshaping
- anthology structure
- **Case:** DN 16 与其他涅槃叙事平行本。
- **Lesson:** Variant ≠ corruption by default.

## EP04｜地下出现两千年前的桦树皮
- Gandhāran manuscripts。
- 早期写本为什么改变研究视野。
- “最老实物”仍然不等于“原稿”。
- **Map:** Gandhāra → modern collections.

## EP05｜丝绸之路上的国际翻译工程
- 印度语/中亚语言 → 汉语。
- translators, reciters, scribes, editors.
- 翻译差异可能来自 source recension，而非译者“翻错”。

## EP06｜鸠摩罗什为什么让佛经突然变好读？
- 译场、人群、语言风格。
- **Case candidates:** Lotus / Vimalakīrti / Diamond.
- literal vs literary translation is a false binary.

## EP07｜玄奘为什么非要自己去印度？
- 学说分歧、版本差异、术语不稳定。
- travel as knowledge infrastructure.
- **Map:** Chang’an → Central Asia → India → Chang’an.

## EP08｜唐代译经场到底像不像现代项目组？
- source text
- oral explanation
- transcription
- verification
- polishing
- cataloguing
- 用现代“translation pipeline”视觉化。

## EP09｜印度原文没了，中文反而成了证据
- survival bias.
- Chinese/Tibetan translations can preserve lost Indic works.
- **Case:** Saṃdhinirmocana complete Chinese/Tibetan recensions, fragmentary Sanskrit evidence.

## EP10｜西藏为什么又保存了一整套不同宇宙？
- Kangyur / Tengyur.
- Translation terminology standardization.
- 不把 Tibetan canon 当成“另一版中文大藏经”。

## EP11｜“伪经”到底是什么意思？
- apocrypha is not one simple category.
- traditional attribution / local composition / adaptation / revealed status.
- **Cases:** Śūraṅgama, Awakening of Faith, Chinese compositions.
- 不以“假”替代细致的 provenance analysis.

## EP12｜今天怎么重建一部已经不存在的祖本？
- Work → Version → Witness → Parallel → Variant → Model.
- certainty labels: consensus / probable / disputed / unknown.
- 最后一幕回到问题：**“真经”不是一个神奇文件，而是一条越来越透明的证据链。**
