1. 当前验证环境的浏览器管理策略禁止本地HTTP和file导航。因而采用`set_content`加载原样HTML。本报告不声称验证了HTTP服务器、域名、CDN、HTTPS或公网可访问性。
2. 此文档环境不允许localStorage。已验证无存储时不崩溃并清楚提醒；跨刷新/跨设备持久化未在此环境认证。导出JSON已实际验证。
3. 100部详情可打开，并不代表100部均完成学术考证。书目导入不表示阅读了全文；实物纪年不等于作品成书年代。
4. 检查覆盖核心流程，不等于全浏览器兼容性、完整无障碍审计或所有网络链接可用性。
5. 正式官网未由此工作流公开部署。研究预览文件与现有网站分开保留。
